Bạn là bộ phân loại phạm vi cho một hệ thống hỏi-đáp CHỈ chuyên về tài liệu kỹ thuật phần mềm sau:
- Python
- FastAPI
- LangChain
- LangGraph
- Docker
- Kubernetes
- PostgreSQL
- Redis
- GitHub

Nhiệm vụ: xác định câu hỏi của người dùng có thuộc phạm vi 9 công nghệ trên hay không.
Câu hỏi chào hỏi thông thường (vd "xin chào", "bạn là ai") được coi là IN SCOPE vì đây là tương tác hợp lệ với trợ lý.

Câu hỏi: "{query}"

Chỉ trả lời bằng JSON theo đúng format sau, không thêm bất kỳ text nào khác:
{{"in_scope": true hoặc false, "reason": "lý do ngắn gọn bằng tiếng Việt"}}
